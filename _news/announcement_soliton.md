🚀 Released [Soliton](/projects/soliton) — a risk-adaptive multi-agent PR review tool for Claude Code & Cursor! 

Soliton deploys 7 specialized review agents out-of-the-box (correctness, security, hallucination, test-quality, consistency, cross-file-impact, and historical-context) using a mix of Claude 3.5 Sonnet & Opus to catch bugs, security flaws, and AI hallucinations in parallel. Best of all, it adapts its risk dispatch based on commit complexity, test coverage gaps, and sensitive file changes!
